# 📊 Indian Mutual Funds Analytics Dashboard (Power BI)

## 📌 Project Overview
An interactive Power BI dashboard analyzing **2,098 active Indian mutual fund schemes** across **50 Asset Management Companies (AMCs)**, tracking AUM, expense ratios, and investment plan preferences.

## 🖼️ Dashboard Preview
![Fund Overview Dashboard](Screenshot%20(34).png)

## 🚀 Key Highlights & Insights
- **KPI Metrics:** 2,098 Active Schemes | 50 Fund Houses | 0.33% Avg Expense Ratio | ₹242.16 Avg Latest NAV.
- **Top AMCs:** HDFC and ICICI Prudential lead in GROWTH AUM; Edelweiss leads in IDCW.
- **Features:** Includes interactive slicers for ETFs and Direct Plans.
